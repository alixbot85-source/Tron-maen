# ربات ماینینگ شبیه‌سازی‌شدهٔ TRON

این پروژه یک ربات تلگرام فارسی با Python، `aiogram 3` و SQLite است. ماینینگ در این پروژه شبیه‌سازی‌شده و دستی است؛ هیچ اتصال یا تأیید خودکار بلاک‌چین انجام نمی‌شود. پرداخت پکیج سرعت و برداشت‌ها توسط ادمین بررسی و به‌صورت دستی تأیید یا رد می‌شوند.

## نیازمندی‌ها

- Python 3.10 یا جدیدتر
- یک ربات ساخته‌شده در BotFather
- شناسهٔ عددی حداقل یک ادمین تلگرام

## نصب و اجرا

```bash
cd Tron-maen
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

در لینوکس یا macOS، متغیرهای لازم را تنظیم و ربات را اجرا کنید:

```bash
export BOT_TOKEN='توکن واقعی BotFather'
export ADMIN_IDS='123456789'
export TRON_WALLET_ADDRESS='یک آدرس معتبر TRON با 34 کاراکتر و شروع T'
python bot.py
```

در ویندوز PowerShell:

```powershell
$env:BOT_TOKEN='توکن واقعی BotFather'
$env:ADMIN_IDS='123456789'
$env:TRON_WALLET_ADDRESS='یک آدرس معتبر TRON با 34 کاراکتر و شروع T'
python bot.py
```

برای چند ادمین، شناسه‌ها را با کاما جدا کنید:

```bash
export ADMIN_IDS='123456789,987654321'
```

`BOT_USERNAME` اختیاری است. اگر تنظیم نشود، ربات هنگام اجرا نام کاربری خودش را از تلگرام می‌خواند تا لینک دعوت را بسازد. فایل SQLite با نام `tron_mining_bot.sqlite3` در مسیر اجرا ایجاد می‌شود؛ برای قرار دادن آن در مسیر دیگر، متغیر `DATABASE_PATH` را تنظیم کنید.

> آدرس TRON را می‌توان پس از اجرا نیز از `/admin` و گزینهٔ «آدرس TRON» تغییر داد. مقدار ذخیره‌شده در دیتابیس بر `TRON_WALLET_ADDRESS` در `config.py` یا محیط اولویت دارد.

## تنظیمات

تنظیمات قابل‌تغییر در `config.py` قرار دارند، از جمله:

- `BASE_MINING_RATE`: نرخ پایهٔ پیش‌فرض، `0.01 TRON` در دقیقه
- `MINING_COOLDOWN_SECONDS`: فاصلهٔ حداقل میان دو برداشت ماین، `60` ثانیه
- `MINING_CAP_OPTIONS`: گزینه‌های سقف ماین: 2000، 5000، 10000 و 20000
- `SPEED_PACKAGES`: پکیج‌های سرعت با قیمت‌های 60، 100، 150 و 200 TRON
- `REFERRAL_FIXED_REWARD`: پاداش ثابت دعوت، `0.5 TRON`
- `REFERRAL_MINING_PERCENTAGE`: پاداش درصدی از ماین دعوت‌شده، `10%`

## رابط کاربری

- منوی اصلی و همهٔ مسیرهای کاربر با **Inline Keyboard** تلگرام ساخته شده‌اند؛ دکمه‌های مرتبط دو‌تایی و دکمهٔ «منوی اصلی» در انتهای صفحه‌های فرعی هستند.
- پیام‌ها با کادرهای متنی کوتاه و خوانا نمایش داده می‌شوند. نماد `🔺` و ایموجی‌های محدود برای حفظ حس مینیمال TRON استفاده شده‌اند؛ تلگرام امکان رنگ‌آمیزی واقعی دکمه‌ها را ندارد.
- پیش از تأیید یا رد پرداخت و برداشت، و نیز پیش از تغییرهای دستی حساس در پنل ادمین، یک مرحلهٔ تأیید نهایی نمایش داده می‌شود.

## جریان کار

1. کاربر با `/start` ثبت‌نام می‌کند و از دکمهٔ «برداشت ماین» استفاده می‌کند.
2. مقدار ماین از زمان سپری‌شده، نرخ پایه و ضریب سرعت حساب می‌شود. برداشت ماین حداقل هر 60 ثانیه یک‌بار ممکن است.
3. کاربر سقف ماین را انتخاب می‌کند. پس از رسیدن `total_mined` به سقف، می‌تواند آدرس TRON خود را برای برداشت بفرستد.
4. کاربر برای ارتقای سرعت، یک پکیج انتخاب می‌کند، مبلغ نمایش‌داده‌شده را به آدرس ربات می‌فرستد و TXID را ثبت می‌کند.
5. ادمین از `/admin` درخواست پرداخت یا برداشت را تأیید یا رد می‌کند. با تأیید پرداخت، ضریب سرعت اعمال می‌شود. با تأیید برداشت، موجودی و ماین دورهٔ کاربر صفر می‌شود.
6. لینک دعوت هر کاربر به‌شکل `https://t.me/BOT_USERNAME?start=REF_USER_ID` ساخته می‌شود. تعداد دعوت‌های موفق، پاداش ثابت ثبت‌نام و پاداش درصدی ماین در همان صفحه نمایش داده می‌شود.

## نکات امنیتی و عملیاتی

- فقط شناسه‌های موجود در `ADMIN_IDS` می‌توانند `/admin` و همهٔ دکمه‌های مدیریتی را استفاده کنند.
- TXID تکراری پذیرفته نمی‌شود.
- مبلغ‌های مالی با `Decimal` در برنامه و به‌صورت متن در SQLite ذخیره می‌شوند تا خطای اعشاری float ایجاد نشود.
- از فایل `tron_mining_bot.sqlite3` به‌طور منظم نسخهٔ پشتیبان بگیرید. این فایل شامل کاربران، درخواست‌ها، تنظیمات آدرس و گزارش تغییرات ادمین است.
